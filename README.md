# markliao.dev

My personal portfolio website built with Next.js, TypeScript, and Tailwind CSS. Dark theme with bento grid layout, gradient accents, and smooth scroll navigation.

**Live:** [one-shot-portfolio.vercel.app](https://one-shot-portfolio.vercel.app)

## Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Font:** Inter via `next/font`
- **Deploy:** Vercel

## Run Locally

```bash
npm install
npm run dev
```

## Built With

Scaffolded and designed in a single session using [Claude Code](https://claude.com/claude-code).
